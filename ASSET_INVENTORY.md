# Asset and dependency inventory

## External browser libraries and services

- app.enginex2030.com — configurable app/API origin; pricing, account, and installer-release requests.
- cdn.tailwindcss.com — Tailwind Play CDN used inside the embedded hero scene.
- code.iconify.design — Iconify iconify-icon 1.0.7 runtime.
- cdnjs.cloudflare.com — GSAP and ScrollTrigger 3.12.2 used by the embedded scene.
- fonts.googleapis.com and fonts.gstatic.com — Google Fonts requested by the embedded scene.
- www.googletagmanager.com — Google Analytics script.
- hoirqrkdgbmvpwutwuwj.supabase.co — hosted atmospheric hero backdrop.
- ipn.eg — external InstaPay logo.
- wa.me — WhatsApp contact link.

These are loaded by the source page or embedded hero scene. There are no npm dependencies. The local Cairo fonts and bundled React runtime notices are documented in THIRD_PARTY_NOTICES.md.

## Bundled browser code

- ThreeUI-derived laser/matrix-field hero — included in src/laser-scene.js; the source identifies the adaptation as MIT-licensed.
- React, React DOM, and scheduler runtime — bundled in src/laser-scene.js; Meta Platforms, Inc. and affiliates are identified in its license comments.
